# Reina del Flow Project

## Overview
This project is dedicated to the popular series "Reina del Flow". It includes multiple seasons with dynamic content rendering, allowing users to explore episodes, view details, and enjoy a seamless experience.

## Project Structure
```
reina-del-flow
├── index.html               # Main entry point of the application
├── temporada-2.html         # Second season of the series
├── temporada-3.html         # Third season of the series
├── css
│   ├── styles.css           # Main styles for the application
│   └── responsive.css       # Responsive styles for different screen sizes
├── js
│   ├── main.js              # Main JavaScript file for application logic
│   ├── episodes.js          # JavaScript file for handling episode data
│   └── player.js            # JavaScript file for media player functionality
├── images
│   ├── thumbnails           # Thumbnails for episodes
│   ├── posters              # Posters for the series
│   └── icons                # Icons used in the application
└── README.md                # Documentation for the project
```

## Setup Instructions
1. **Clone the repository**: 
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd reina-del-flow
   ```

3. **Open `index.html` in your browser** to view the application.

## Features
- Dynamic content rendering based on the selected season.
- Responsive design for optimal viewing on various devices.
- Organized structure for easy navigation and maintenance.
